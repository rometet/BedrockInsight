# BedrockInsight

**Still in development.**

A server-side Minecraft Bedrock Edition analytics and statistics mod for LeviLamina, with a read-only web companion.

Target: Bedrock Dedicated Server 1.26.60.6 / LeviLamina 26.60.0.

This repository is an early source-code snapshot. LK-Stats feature parity is **not complete**. APIs, statistic semantics, and installation instructions may change. It is not ready for production use.

No release packages are published yet.
