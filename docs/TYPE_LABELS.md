# 種類名の日本語表示（候補ソース・未配備）

`companion/lang/ja_JP.json` をWebとネイティブGUI／C APIで共有します。
独立作成した138件の一般的なブロック・アイテム・Mobの表示名です。
全バージョン・全種類の網羅や、その種類の行動捕捉を保証するレジストリではありません。
未知IDは `addon:widget` のような元IDを表示します。保存済みID・値・単位・順位は変更せず、
DB移行／書き込みも行いません。CUSTOM77キーは観測段階を明示する既存ラベルを優先し、
種類名ファイルから上書きできません。

既存BDS・旧SQLite・稼働中18767は更新していません。この追補は完全同等性や実機受入の
達成を意味しません。実機操作→SQLite→ゲーム内GUI／互換APIの受入は引き続き必要です。

## 任意の表示名ファイル

UTF-8（BOMなし）で利用者の新しい私有ファイルに保存します。例：

```json
{
  "schema_version": 1,
  "locale": "ja_JP",
  "labels": {
    "minecraft:stone": "石",
    "addon:widget": "追加部品"
  }
}
```

既定の辞書へマージする表示設定です。HTTPからファイル指定・書き換え・再読込はできません。
種類IDは小文字ASCIIの名前空間付きID、3～128文字。ファイル最大128KiB、最大4096項目
（マージ後も4096）、表示名は空でない256 UTF-8バイト以内です。
重複JSONキー、未知のルート項目、別schema／locale、不正UTF-8、改行・C0/C1制御文字・
U+2028/U+2029は拒否します。表示名はコードやHTMLとして実行しません。
表示ラベルはローカル管理者の信頼する内容を使い、秘密情報を入れないでください。

## Webコンパニオン

新規プロセスを利用者が別の空きloopbackポートで起動する場合だけ、追加指定できます。
18767を停止・再起動・置換する手順ではありません。

```powershell
python -m companion.server --database "C:\path\to\private-copy.sqlite3" --port 18768 --type-labels "C:\path\to\type-labels.json"
```

18768は例であり、この作業では常駐起動していません。バインドは127.0.0.1固定。
新プロセスのコンソールに出た8時間有効の閲覧トークンを
`http://127.0.0.1:18768/stats` に入力します。トークンをURLや共有ログに残さないでください。
メインPCからの閲覧は既存の私有SSH転送のみ。LAN／Tailscale／公開バインドはしません。

種類欄には日本語表示名と元IDを併記し、どちらでも検索できます。
同じ表示名を複数IDに付けても合算しません。種類指定・C APIのkeyは元IDのままです。
ファイルはbind前に一度だけ読み、サーバーごとの不変スナップショットを使います。
不正な任意ファイルなら起動を拒否し、既存プロセスには影響しません。
同梱ファイルが欠損／不正ならPythonの起動も失敗します。元ファイルの保全が必要です。

## ネイティブ候補

候補パッケージは `BedrockInsight/lang/ja_JP.json` を同梱します。
`Runtime::load` で `getModDir()/lang/ja_JP.json` を読み、任意に
`getConfigDir()/type_labels.ja_JP.json` を一度だけマージします。
設定ファイルの自動作成・書き込み・ホットリロード・追加フックはありません。
欠損／不正な設定は警告し、直前の有効な辞書（なければ元ID表示）を保持します。
ゲームスレッドのイベントごとにファイルを読みません。

個人明細と順位の種類見出し、および独立C APIのentry.labelへ接続しています。
4関数のABI・元key・値型・単位・ページは変えません。LegacyRemoteCall互換を追加した
という意味ではありません。[現行C API契約](NATIVE_STATS_API.md)も参照してください。
`xmake.lua` のローカルmodpacker出力にも同じassetをコピーする定義を加えましたが、
実際の最終ビルド検証はSTATUS記載のPowerShell候補手順で、xmake経路の実行証明ではありません。

稼働BDSにこのDLL／辞書／設定をコピーしないでください。実機確認は承認済み通常ホストの
新root・未使用world／portsで別途行い、全77キーの受入を進めます。

## 検証の範囲

併せてジャンプの旧表示を「ジャンプ通知（旧加速観測を含む）」に揃えました。
現行PlayerJumpEventのpost_auth_input通知と、旧PosDelta履歴の両方を明示します。
加速計測・空中移動完了を現行イベントから推測しません。保存値や捕捉処理は変更しません。

C++で既定／上書き／未知ID・CUSTOM優先・不正設定の原子的拒否・容量境界と、
合成イベント→StorageWriter→SQLite→C APIのラベルと元ID／値を照合します。
Pythonは認証401/200、日本語検索、別サーバーとの分離、不正設定のbind前拒否、
SQLiteバイト非変更を確認。実際のstats.jsを合成DOMで動かし、HTML風ラベルをtextContentで
表示することも検証します。実ブラウザ／実プレイ／ゲーム内GUIの証明には数えません。
コマンド・最終証跡は[STATUS](../STATUS.md)を参照してください。
